# AI Task Manager

個人向けのAIタスク管理アプリです。CLEの予定と課題を取り込み、締切・重要度・空き時間・生活リズムを考慮して「今日やるべきこと」を自動で提案します。

## 主な機能

- CLE共有URLから課題と予定を取得
- 重要度・締切・空き時間をもとに優先度を算出
- 生活リズム（睡眠・食事）を考慮した今日の提案
- 手入力タスクの追加・編集・削除
- 学習計画と類題の自動生成
- 授業名・資料名のローカル保存
- ローカルAPIとの同期とPDF/テキスト抽出

## 技術構成

- Flutter/Dart: フロントエンド
- SharedPreferences: ローカル保存
- Python HTTP server: 文字抽出とローカル同期用API

## 実行方法

### Flutterアプリ

```powershell
flutter pub get
flutter run
```

### ローカルAPI

```powershell
python server.py
```

APIは `http://127.0.0.1:8000` で起動します。

## 使い方

1. アプリ起動後、ホーム画面でCLE共有URLを設定します。
2. 学習優先順位AIで課題を読み込みます。
3. 今日やることに自動配置されたタスクを確認します。
4. 必要に応じて手入力タスクや学習計画を追加します。

## 重要事項

- ログイン機能やマルチユーザー共有は想定していません。
- 本アプリは個人利用のローカルファースト設計です。
- Web公開する場合は、Flutter WebのフロントエンドとPythonバックエンドを分けてホスティングするのが適切です。
